## Common Command Line Commands
The command **`mkdir`** is used to create a folder 📁 with a name of your choice.

Here is an example:

mkdir folder1

---

The command **`touch`** is used to create a file 🗂️ such as *.md* and *.txt* inside of a folder.

Here is an example:


cd folder1    
touch file.md  
touch file2.txt  

---
The command **`list`** is used to *list all the current folders* in the directory.

Here is an example:


  ls

  Output: folder1 file.md file2.txt

---
The command **`cd`** is used to *enter* a folder that is *specified* 🚪

Here is an example:
 
  cd folder1

  ---

Now you are in folder1. You can check using **pwd**

The command **`pwd`** is used to see your *current* location. 🗺️

Here is an example:  



  `pwd`

Output: /workspaces/folder1
